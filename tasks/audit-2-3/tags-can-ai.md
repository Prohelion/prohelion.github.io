## Section-level observations

- **No page declares a type.** None of the 20 pages has `type:`, `owner:` or `last_reviewed:`. Fifteen of the 20 pages mix two or more page types. Add `type:` as each page is refactored, starting with the ones marked SPLIT_INTO.
- **The Rules, Actions and Alerts split is half done.** Rules.md holds action inheritance, Actions.md repeats the rule intro, and Alerts.md holds the dwell and deadband section. Move each one to its owner before splitting the files further.
- **Procedures live in both the feature page and the how-to.** The CAN replay and send/receive pages duplicate How_To_Guides/Replay_CAN_Logs.md and How_To_Guides/Send_Receive_CAN_Bus.md. The tag replay page repeats the CAN replay admonitions. Keep one home per procedure and link to it.
- **Duplicated reference content:** Mobile/index.md repeats the Discovery settings table. Collections.md repeats the Tag_Expressions membership examples. CAN_Bus_DBC.md repeats the Custom_Components DBC instructions. Keep each table in one place.
- **Task pages need numbered steps, prerequisites and a verify step.** Affected: CAN_Bus_DBC, Send_Receive_CAN, Tag_Linking, Script_Driven_Derived_Tags, Tag_Tree_Path, AI_Skills (install), AI_Chat, OEM_White_Label, Mobile/index (connect), Logging_Replaying_Tags (logging setup).
- **Stale or audience issues to resolve before publication:** the Early Adopters notice in Mobile/index.md, and in Installation/Windows_Installation.md and Zip_Installation.md (outside this section); the partner build guide in OEM_White_Label.md; and version phrasing such as "As of Profinity 2.3" in Tag_Relay.md and Tag_Tree_Path.md.
- **Accuracy checks before publication:** Tags/Actions.md says "two built-in actions" and then lists four, and its diagram alt text names PagerDuty. Profinity_AI/index.md makes capability claims that need checking against the shipped product. Fix the broken sentence there too.
- **Suggested Tags page list after the split (sentence-case names, one type each):** Tag layer (overview, `index.md`); Rules (rules.yaml reference and visual editor, reference); Rules worked example (reference or tutorial); Rule actions (concept, with TriggeredTags and placeholders); Email and Slack rule actions (reference); Webhook and MQTT rule actions (reference); Alerts Log (reference, now with alert levels); Collections (concept and reference); Create a collection (task); Derived tags (concept and reference); Create a derived tag (task, optional); Script-driven derived tags (task); Tag expressions (reference); Create collections, rules and dashboard bindings from tags (task, from Tag_Linking); Tag relay (concept); Troubleshoot a tag relay sender (task); Nest a component in the tag tree (task); Tag tree paths and dashboard binds (concept and reference); Log tags to a file (task); Replay a tag log (task).
