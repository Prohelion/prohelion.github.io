## Decisions

- Four file and SFTP components became two component pages, not four. The SFTP variant of each logger differs from the file variant only by destination, so a page per SFTP logger would be under 150 words of real content and would repeat the file logger page. The SFTP connection settings and the rotation and archive settings are used by both CAN and TAG loggers, so they moved once to a shared reference page (the rotation text existed once in the source, but both new component pages need it, so it could not stay on either).
- Page name for the shared reference combines SFTP settings with rotation and archive because both are shared by the same four components and neither is long enough to stand alone (SFTP is about 130 words).
- The download section is split between the two component pages: each carries its own link label (**FILE LOGS REPOSITORY** on the CAN page, **TAG LOGS REPOSITORY** on the Tag page). The screenshot stays on the CAN page, where its alt text (File Logs Repository link) matches.
- InfluxDB page: kept the name InfluxDB_v1_Logger.md rather than InfluxDB_Logger.md because the version is the distinguishing fact.
- Historians: InfluxDB_Historians.md and TAG_SQL_Historian.md left as they are except for links, as instructed. No split.
- Comparison tables use six columns instead of the audit's eight. Dropped, because the pages state no fact for them: Retry interval (stated only for InfluxDB v1, Prometheus and TAG SQL, and as a variable `<n>` for InfluxDB historians) and Auto Connect default on the Historians table (no historian page states it). The Diagram column was dropped because every row would read Yes. Transport and protocol is carried by the "Where the data goes" and "Stores data in" columns. Licence is kept on both tables for consistency with other categories, although it is identical on every Loggers row.
