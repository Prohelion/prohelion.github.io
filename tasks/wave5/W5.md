3. The reference says the interval must be a whole number from 0 to 4,294,967,295 ms. The how-to says to leave it blank for manual send only. Is blank valid, and is 0 the same as no schedule?
4. Replay slider: the reference says it "moves to a different point in the log" during play, the how-to says it "moves the replay to any position". Does the user drag it during play? Both claims kept.

6. Delete (Remove a component) says "Select delete" with no UI label in bold. I could not confirm the exact label.
