The Security tab holds the instance-wide authentication and access policy. Each group of settings has its own page:

|---------------------------|------|
| Sign-in mode, local login and SSO | [Single Sign-On and Sign In](SSO_and_Sign_In.md) |
| Password policy           | [Password Policy](Password_Policy.md) |
| Two-factor authentication | [Two-Factor Authentication](Two_Factor_Authentication.md) |
| SCIM provisioning and SIEM export | [SCIM and SIEM](SCIM_and_SIEM.md) |
