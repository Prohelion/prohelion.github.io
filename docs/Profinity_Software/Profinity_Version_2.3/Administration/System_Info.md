# System Information

To see which version of Profinity you are running, select **ADMIN** in the side menu, then the **System Information** pill.

<figure markdown>
![System Information page showing version, active memory, diagnostics and release history](../images/system_info.png)
<figcaption>System Information Page</figcaption>
</figure>

The page lists the version, the authors and the active memory in use, followed by a **New Release Available** banner when a newer Profinity release has been detected. The **System Diagnostics** section shows the **License Status** (see [Licensing](Licensing.md)), the operating system and the system uptime, and the **Release History** section lists the current release and earlier versions, with the software credits.

## Restarting Profinity

The **Restart Profinity** pill on the **ADMIN** page, shown to users with the **Security administration** permission, restarts Profinity after a confirmation that reads "Restarting Profinity will interrupt all active sessions. Are you sure you want to continue?", so choose a time when nobody is part-way through a task.
