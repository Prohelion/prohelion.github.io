# Visualising Data

Each configured component has a [dashboard](../Customising_Profinity/Dashboards/index.md), opened by selecting the component in the sidebar, that shows the data for that component type.

<figure markdown>
![A WaveSculptor component dashboard visualising data](../images/wavesculptor.png)
<figcaption>Example of Dashboard Visualising Data</figcaption>
</figure>

A dashboard stays empty until data arrives. [How to Connect to CAN Bus](../How_To_Guides/Connect_to_CAN_Bus.md) brings in live data from a CAN bus adapter, [How to Replay CAN Bus Logs](../How_To_Guides/Replay_CAN_Logs.md) supplies recorded data when no hardware is connected, and the [Tag Explorer](../Tags/index.md), opened from **TAG UTILITIES** in the side menu, shows the tags and their current values.

To see how a dashboard is built, or to create your own, see [How to View Dashboard Source](../How_To_Guides/View_Dashboard_Source.md) and the [Dashboard Development Guide](../Customising_Profinity/Dashboards/index.md).
