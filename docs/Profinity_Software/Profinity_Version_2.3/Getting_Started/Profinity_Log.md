# Profinity System Logs

Profinity has a built-in logging mechanism that captures information about the operation of the system and is designed to assist in diagnosing system issues. To access the system logs, select **ADMIN** in the side menu, then the **Logs** pill.

!!! info "Expanding Log Lines"
    If a log line goes off the right hand side of the page because it is too big, you can click on the line to expand that log message.

<figure markdown>
![Profinity Log](../images/system_logs.png)
<figcaption>Profinity System Logs</figcaption>
</figure>

Each log entry contains a timestamp, a message level (for example `Info`, `Warn` or `Error`), and a message description. To help diagnose particular issues, the scope of the system logs can be changed to only include particular message levels. More information about varying the displayed log levels can be found in [Logs](../Administration/System_Configuration/Logging.md) in the Administration section.
