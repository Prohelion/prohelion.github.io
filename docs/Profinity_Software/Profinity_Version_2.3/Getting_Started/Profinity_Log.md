# Profinity System Logs

A built-in [logging mechanism](../Administration/Logs_Config.md) records the operation of the system, which helps diagnose issues. To access the system logs, select **ADMIN** in the side menu, then the **Logs** pill.

!!! info "Expanding Log Lines"
    If a log line goes off the right-hand side of the page because it is too big, click on the line to expand that log message.

<figure markdown>
![Profinity Log](../images/system_logs.png)
<figcaption>Profinity System Logs</figcaption>
</figure>

Each log entry contains a timestamp, a message level (for example `Info`, `Warn` or `Error`), and a message description. To help diagnose particular issues, the **Log Level** option on the **Logging** tab of System Configuration limits the system logs to particular message levels, and [Logging](../Administration/System_Configuration/Logging.md) describes the log levels.
