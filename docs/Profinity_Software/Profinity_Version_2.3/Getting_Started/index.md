# Getting started with Profinity

These pages take a new Profinity 2.3 user from a first install to live data on a dashboard.
Work through them in order, or go straight to the page you need.

- [Quick start guide](Quick_Start.md): install Profinity, load an example profile, replay a CAN log, edit your first dashboard, and look at rules and alerts.
- [Create a user](Create_User.md): create a user, set an initial password, and assign roles. This needs a Server licence, so skip it until you need other people to sign in.
- [Profinity profiles](Profiles.md): learn how a profile organises the configuration, components, dashboards, and settings of a setup.
- [How to add a component to your profile](../How_To_Guides/Add_Component_to_Profile.md): add hardware devices and protocol adapters from the web interface.
- [Profinity dashboard development guide](../Customising_Profinity/Dashboards/index.md): see component data on the built-in dashboards, and build your own.
- [Logs](../Administration/Logs_Config.md): read the timestamped log entries when you troubleshoot.
- [Glossary](Glossary.md): look up Profinity terms and acronyms.

To install on a specific platform, refer to [Installing Profinity](../Installation/index.md).
