# Getting started with Profinity

These pages take a new Profinity 2.3 user from a first install to live data on a dashboard.
Work through them in order, or go straight to the page you need.

- [Quick start guide](Quick_Start.md): install Profinity, apply a licence, load an example profile, replay a CAN log, edit your first dashboard, and look at rules and alerts.
- [Create a user](Create_User.md): create a user, set an initial password, and assign roles.
- [Profiles](Profiles.md): how a profile organises configuration, components, dashboards, and settings for a setup.
- [Adding components to your profile](Adding_New_Components.md): add hardware devices and protocol adapters from the dashboard interface.
- [Visualising data](Visualising_Data.md): see component data on the built-in dashboards.
- [Profinity system logs](Profinity_Log.md): read the timestamped log entries when you troubleshoot.

To install on a specific platform, refer to [Installation](../Installation/index.md).
