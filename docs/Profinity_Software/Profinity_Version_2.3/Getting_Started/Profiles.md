# Profinity profiles

A profile holds the configuration of your system.
Any component that you add becomes part of the active profile, and Profinity keeps the configuration of each device after it shuts down.
Profinity tracks your profiles and loads the most recently used one each time it starts.

Each profile keeps its own set of components, dashboards, and settings.

## Managing profiles

To manage profiles, select **ADMIN** in the side menu, then the **Profile** pill.
The profile list shows every profile, and each row can be viewed, edited, or deleted.

- **ACTIVATE** on a row makes that profile the active profile. Use it to switch between system configurations or to test different setups.
- **Add profile** creates a new profile.
- **Upload Profile Pack** imports a profile from another Profinity instance.

[How to create a new profile](../How_To_Guides/Create_New_Profile.md) gives the steps for creating one.
