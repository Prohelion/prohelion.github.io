# Chargers and power supplies

Profinity charges a battery pack by controlling a charger and a Prohelion Battery Management Unit (BMU) together.

- [Charger components](Charger_Components.md): choose a TDK Power Supply, Siglent Power Supply or Elcon Charger and add it to a Profile.
- [Charger settings](Charger_Settings.md): look up the charger and supply limits and the network and CAN settings.
- [Start a charge](Start_a_Charge.md): select the battery, set the current and **Charge To** level, and press **START**.
- [Charging troubleshooting](Charging_Troubleshooting.md): fix the controller messages and a pack that does not engage.
