# CAN bus adapters

An adapter connects Profinity to a CAN bus, so the components on that bus can send and receive messages.

- [CAN bus adapters](CAN_Bus_Adapters.md): add and configure Prohelion and Tritium CAN to Ethernet bridges, Peak USB, SocketCAN, SocketCANd, and the Ewert Energy CANdapter.
- [Virtual CAN adapter](Virtual_CAN_Adapter.md): relay traffic between CAN devices and bridge protocols.

For the steps to connect a CAN bus, refer to [How to Connect to CAN Bus](../../How_To_Guides/Connect_to_CAN_Bus.md).
