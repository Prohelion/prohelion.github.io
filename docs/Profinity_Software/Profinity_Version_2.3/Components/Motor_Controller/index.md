# Motor controllers

Profinity monitors Prohelion WaveSculptor22 and WaveSculptor200 motor controllers over CAN.

- [WaveSculptor motor controller](WaveSculptor/index.md): add a WaveSculptor to a Profile and set its name, timeout, and base address.
- [WaveSculptor dashboard](WaveSculptor/WaveSculptor_Dashboard.md): read the bus data, limit indicators and error indicators.
- [Update WaveSculptor configuration and firmware](WaveSculptor/Update_WaveSculptor_Configuration_and_Firmware.md): run wsConfig and flash the firmware from a Windows desktop instance.
