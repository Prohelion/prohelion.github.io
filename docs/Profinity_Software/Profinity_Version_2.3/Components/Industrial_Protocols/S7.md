# S7

The **S7 PLC** component is an S7comm client for Siemens PLCs. It connects to one PLC and polls the addresses you list in its point map, publishing each one as a Profinity tag. It supports S7-300, S7-400, S7-1200 and S7-1500 controllers.

The S7 plugin is not included in the standard Profinity installation. It is supplied by Prohelion on request and installed like any other [DLL plugin](../../Administration/Components_and_Plugins.md). It also requires the **Industrial Protocols** licensed component group; see [Licensing](../../Administration/Licensing.md). See [Industrial protocols](index.md) for an overview.

You add an S7 PLC to your [Profile](../../Getting_Started/Profiles.md) from the **Industrial Protocols** group in the component catalogue, as described in [Adding Components to Your Profile](../../Getting_Started/Adding_New_Components.md). Add one component for each PLC you want to read. The settings below can be changed later from the component's `Change Settings` menu.

!!! info "What this version supports"
    The component uses absolute addressing only. You specify the memory area and byte offset of each value, and symbolic tag names are not supported. For symbolic access to an S7-1200 or S7-1500, use the [OPC UA Client](OPC_UA.md) against the PLC's OPC UA server.

!!! warning "Prepare the PLC"
    S7-1200 and S7-1500 PLCs must have **Put/Get** access enabled before they will answer, and data blocks must not use optimised block access, because optimised blocks cannot be read by absolute address. Both are changed in the PLC's project, so speak to whoever maintains the PLC program.

## Communications settings

| Setting | Description |
|---|---|
| `Name` | The name of the component. Must be unique within the profile. |
| `Host` | The IP address of the PLC. Required. The default is `127.0.0.1`. |
| `Port` | The TCP port. Between `1` and `65535`. The default is `102`. |
| `Rack` | The rack number of the PLC. Between `0` and `7`. The default is `0`. |
| `Slot` | The slot number of the CPU. Between `0` and `31`. The default is `1`. |
| `CPU type` | The PLC family: `S7-300`, `S7-400`, `S7-1200` (the default) or `S7-1500`. |
| `Poll interval (ms)` | How often the point map is read. Between `50` and `600000`. The default is `1000`. |
| `Request timeout (ms)` | How long Profinity waits for the PLC to answer a request. Between `50` and `60000`. The default is `1000`. |
| `Reconnect delay (ms)` | How long Profinity waits before trying to reconnect after a connection is lost. Between `0` and `600000`. The default is `2000`. |
| `Auto Connect` | Connects to the PLC automatically when the profile is loaded. Off by default. |

The usual rack and slot is `0` and `1` for S7-1200 and S7-1500 controllers, and `0` and `2` for most S7-300 controllers, but check your hardware configuration.

## Point map

The point map lists the PLC addresses to read. Each row becomes one tag.

| Column | Description |
|---|---|
| `Name` | The name of the tag, published under the component's `Points` tags. Use a unique name for each row. |
| `Area` | The memory area: `DataBlock` (the default), `Memory` (M), `Input` (I) or `Output` (Q). |
| `DB number` | The data block number. Used only when the area is `DataBlock`, and ignored otherwise. The default is `1`. |
| `Offset` | The byte offset within the selected area. |
| `Data type` | How the value is read: `Boolean`, `Word` (the default), `SignedWord`, `Dword`, `SignedDword` or `Real`. |
| `Writable` | Allows Profinity to write the PLC value from the tag. Off by default. |
| `Unit` | An optional unit label for the tag. |

The data types map to the width of the value in the PLC, and to the type of the Profinity tag.

| Data type | Size | Profinity tag |
|---|---|---|
| `Boolean` | 1 bit | Boolean |
| `Word` / `SignedWord` | 2 bytes (unsigned / signed) | Integer |
| `Dword` / `SignedDword` | 4 bytes (unsigned / signed) | Integer |
| `Real` | 4 bytes (floating point) | Number |

A `Boolean` point reads bit `0` of the byte at the offset, which is the address `DB1.DBX10.0` for data block 1, offset 10. Other types are read as, for example, `DB1.DBW10` (word) or `DB1.DBD10` (double word or real).

!!! warning "Writing to a PLC"
    A write is only accepted when the point's `Writable` option is on. Leave it off for any value that Profinity should only monitor, and consider the effect on the controlled process before enabling it.

## Dashboard

The component dashboard shows the connection `STATUS`, whether the PLC is `CONNECTED`, and the number of messages `RECEIVED` and `SENT`. Use the `Connect / Disconnect` control to start or stop polling manually. Viewing the dashboard requires the Security Admin permission.

Polled values behave like any other tag, so they can be shown on a [dashboard](../Dashboard/index.md), logged, watched by a rule, or read by a script. If a point cannot be read, its tag is marked as bad quality. Check the [Logs](../../Getting_Started/Profinity_Log.md) for the reason.
