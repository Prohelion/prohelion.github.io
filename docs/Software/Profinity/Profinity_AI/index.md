# Profinity AI

Profinity AI gives AI the context of a running Profinity system, so it can work across devices rather than one signal at a time.
AI Chat and the built-in Model Context Protocol (MCP) server require the **AI** licensed feature, included in the **Server** and **Enterprise** editions, as listed in [Licensing](../Licensing.md).

- [How Profinity AI uses your profile](./How_Profinity_AI_Works.md): what Profinity AI can see and how it reaches a diagnosis.
- [AI Chat](./AI_Chat.md): the assistant built into Profinity, for questions about this instance such as system health, alert investigation, and how-to questions.
- [AI Skills](./AI_Skills/index.md): a toolkit for your own AI tool (Claude Code, Cursor, Codex, ChatGPT), for building dashboards, rules, collections, scripts, plugins, derived tags, and example apps from your live schema.
- [Install AI Skills](./AI_Skills/Install_AI_Skills.md): set up AI Skills in your AI tool.
- [AI Skills reference](./AI_Skills/AI_Skills_Reference.md): the skills and what each one does.
- [Profinity AI settings](../Administration/System_Configuration/AI_Settings.md): administrator configuration, permissions, and data-handling notes.
- [MCP Server](../Integrating_to_Profinity/MCP_Server/index.md#choose-a-setup-guide): setup guides for using your own AI tool with the MCP server.
