### Open questions for engineering (not blocking docs)

- **A33 script-driven derived tags — needs test coverage.** Three new shipped example scripts were added to demonstrate the script-driven derived-tag pattern, matching the site's established C#/Python/Lua parity convention: `Default-Profinity-Dir/example_scripts/CSharp/CSharpDerivedTagTemplate.cs`, `.../Python/PythonDerivedTagTemplate.py`, and `.../Lua/LuaDerivedTagTemplate.lua` (all three verified by hand against `IScriptTagAccess`/`ProfinityScriptTags`/`IProfinityTagChangeScript`'s real signatures — the Lua one specifically against `LuaTagChangeScriptEngine.cs`'s `LuaState[PROFINITY_VARIABLE] = SharedProfinityVariables` wiring and NLua's colon-call convention for instance methods — but none executed). This is independent of A33's engine work — it only exercises already-shipped scripting capability (`Run On Tag Change` + `Profinity.Tags`) — so it can be picked up without waiting on A33's Build step. Requesting a `Profinity-Test` case that loads and runs all three scripts and asserts the computed km/h value; no existing test does this for *any* shipped example script today (`ShippedSampleLayoutTests.cs` only checks the files exist), so this would be new test infrastructure, not an extension of an existing pattern.

- **D34 Licensing — `LocalTrialEvaluator` status quirk.** The evaluator marks any local trial with ≤30 days remaining as `Expiring` rather than `Trial`, but the trial's own maximum duration is 14 days — in practice a local trial will likely always report `Expiring`, never plain `Trial`. Documented factually as observed behaviour in `Administration/Licensing.md`, but worth an engineering look at whether this is intended.
- **D36 Tag Tree Path — dashboard staleness on component relocation.** `ComponentRelocationSync` auto-rewrites `rules.yaml`, `collections.yaml`, and the profile home dashboard when a component is renamed/relocated, but does not touch absolute binds inside *other* components' own individual dashboards that reference the moved component — those go stale silently, and historian data orphans at the old path. Covered with a `!!! warning` in the new page; confirm whether this is an accepted MVP gap or worth a code fix.
- **A32 GA-features table** — fixed: A32 was missing from `plans/2.3/Profinity-2.3-Release-Todo.md`'s master GA-features table due to the 2026-09-23 renumbering; a row has been added marking it Complete.
