# Create a widget

Create a widget for each value a dashboard needs to show.
You need the **Edit profiles** permission.

1. In the side menu, select **ADMIN**, then **Widgets**.
2. Select **+ Add widget**, and enter a name.
3. Save the widget.

The widget appears in the list, ready for a dashboard to use.
